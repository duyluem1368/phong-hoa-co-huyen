# Phòng Hóa Cô Huyền

Website MVP tĩnh dành cho giáo viên Hóa học THPT.

Bao gồm phòng thí nghiệm ảo với thư viện phản ứng được kiểm duyệt, mô phỏng hiện tượng, phương trình cân bằng và giải thích bản chất.

## Chạy trên máy

```bash
cd website
python3 -m http.server 8080
```

Mở `http://localhost:8080`.

## Tùy chỉnh trước khi xuất bản

- Thông tin giáo viên: cô Nguyễn Thị Huyền, Trường THPT Xuân Phương.
- Thay các số liệu minh họa bằng số liệu thực tế.
- Nối form đăng ký với Google Forms, Formspree hoặc backend riêng.
- Thay khối chân dung minh họa bằng ảnh thật nếu muốn.

Website có thể triển khai miễn phí trên GitHub Pages, Netlify hoặc Cloudflare Pages.
